# Glossary

## Agent

An AI-powered process or tool that may request MCP tool calls.

## Approval Record

A local JSONL entry documenting an approval request, approval decision, or rejection decision.

## MCP Server

A server that exposes tools to agents through the Model Context Protocol.

## Policy

The configured behavior for a server/tool pair: `allow`, `approve`, or `block`.

## Policy Pack

A built-in starter set of policies for a common MCP server category.

## Proxy Event

An experimental record written by `mcpguard proxy evaluate`.

## Report

A Markdown governance summary generated by `mcpguard report`.

## Simulation

A local policy evaluation for a proposed MCP tool call.
