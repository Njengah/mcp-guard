# Future Roadmap

## Live MCP Proxy

Run MCPGuard as a gateway between agents and MCP servers so real tool calls are evaluated before execution.

## AgentTrace Integration

Attach policy decisions and approval records to AgentTrace run IDs for end-to-end auditability.

## Policy Packs

Ship reusable policy templates for common MCP server categories such as source control, file systems, databases, browser automation, and production APIs.

## Sensitive-Data Redaction

Add configurable redaction rules for secrets, credentials, PII, and internal identifiers in logs and reports.

## Dashboard

Provide a local or hosted dashboard for reviewing policies, simulations, risks, and approval activity.

## Team Approval Workflow

Support approval actors, approval expiration, signed decisions, and team policy synchronization.
