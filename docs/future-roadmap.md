# Future Roadmap

The initial roadmap sequence is complete. The items below are candidate next milestones.

## Live MCP Proxy

Turn the experimental proxy decision path into a live gateway between agents and MCP servers so real tool calls are evaluated before execution.

## AgentTrace Integration

Attach policy decisions and approval records to AgentTrace run IDs for end-to-end auditability.

## Dashboard

Provide a local or hosted dashboard for reviewing policies, simulations, risks, and approval activity.

## Team Approval Workflow

Support approval actors, approval expiration, signed decisions, and team policy synchronization.
